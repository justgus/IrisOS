**Status:** Active
**Owner:** System Engineer
**Start Date:** TBD
**Target Close Date:** TBD

**Goal:**
Deliver the full Caliper catalog and the runtime and Conch conversion tooling required by AR-0019.

**Rationale:**
The Caliper catalog, runtime conversion engine, and Conch commands form a cohesive delivery track under AR-0019.

**Acceptance Criteria:**
- AC-0020: The canonical Caliper catalog covers SI base and derived units, common metric prefixes, and common imperial/US customary units. Each entry has a canonical name, symbol, dimension, system tags, and explicit conversion metadata; duplicate symbols and ambiguous definitions are rejected, and catalog serialization is deterministic.
- AC-0021: The shipped base Caliper catalog is versioned and stored as a durable Referee object. User extensions layer over an immutable base catalog, and any override follows documented explicit precedence rules with deterministic conflict handling.
- AC-0022: The Caliper runtime API checks compatibility by dimension and converts compatible values through deterministic direct or chained conversions, including scale and offset units. It rejects unknown units and incompatible dimensions, documents numeric precision and rounding behavior, and returns stable results across catalog reloads.
- AC-0023: Conch provides commands to list units, inspect unit metadata, and convert values through the Caliper APIs. Commands follow existing naming, output, and error conventions; tests cover successful operations plus unknown-unit and incompatible-dimension errors.
